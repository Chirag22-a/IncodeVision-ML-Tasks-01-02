# IncodeVision ML Internship: Tasks 01 and 02

Two Python projects completed against the IncodeVision internship task briefs.

## Task 01: Data Cleaning and Visualization
Cleans and explores the Titanic teaching dataset. It handles missing values, removes exact matching rows, fixes selected data types, flags numeric outliers for review, and saves a cleaned CSV, summary, and EDA charts.

## Task 02: Linear Regression House Prices
Trains a scikit-learn Linear Regression pipeline on the California Housing dataset, evaluates it on a held-out test set, and saves metrics and diagnostic plots.

## Run a task
Open PowerShell in the task folder, then run: py -m venv .venv followed by .\.venv\Scripts\python.exe -m pip install -r requirements.txt and .\.venv\Scripts\python.exe main.py.

Each task folder contains its own README and dependency list. Dataset sources and limitations are documented there. The California Housing sample downloads on first run.
